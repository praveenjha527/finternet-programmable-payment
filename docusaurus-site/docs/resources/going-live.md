# Going Live

Use this checklist before moving to production.

## Checklist

- Verify production API keys
- Configure webhooks for all critical events
- Review rate limits and retry strategies
- Ensure logging, alerting, and monitoring are enabled
- Validate settlement destinations and bank details
- Run end-to-end tests in production mode
